# Sentiment-Dashboard
The provided Sentiment Dashboard is a strong portfolio piece showcasing proficiency in Natural Language Processing (NLP), Data Science, and Interactive Web Development.



🌟 Demonstrated Technical Skills
The project effectively showcases a range of technical and analytical capabilities:



Natural Language Processing (NLP): Demonstrates the ability to implement real-time sentiment classification using the Hugging Face Transformers pipeline.




Data Science & Analysis: Shows competence in data manipulation using Pandas for handling text input and batch CSV uploads. The analysis includes visualizing sentiment distribution with charts and creating Wordclouds for both positive and negative texts.






Interactive Web Development: Expertise in building a fully functional and interactive web application using Streamlit.




Software Engineering: The setup includes clear installation instructions and dependency management (via requirements.txt), ensuring the project is easily reproducible.



✨ Project Effectiveness and Features
The dashboard is highly effective due to its practical application and user-friendly design:




Usability: It offers both single text input and batch CSV upload capabilities, catering to different user needs.



Visual Insights: The inclusion of both label distribution charts and Wordclouds adds significant instructional value, providing both quantitative and qualitative insights into the analyzed data.



Clarity: The application uses a pretrained transformer sentiment pipeline, indicating the use of modern, high-accuracy machine learning techniques.



Data Output: Users can download analyzed results as CSV, making the dashboard an integrated part of a larger data workflow.
